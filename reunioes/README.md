# Reuniões

Uma nota por reunião, nome `AAAA-MM-DD-assunto.md`, criada a partir de `_templates/reuniao.md`.

**Regra de ouro:** o relatório bruto do Plaud SEMPRE entra na seção final da nota (nunca se perde o original). Decisões, dores e ações são extraídas pro topo e linkadas.

⏳ **Pendente de ingestão:** as 2 reuniões iniciais gravadas (relatórios Plaud) — colar aqui ou entregar os arquivos pro Claude estruturar.
