# CANAIS OFICIAIS (OS TRÊS ÚNICOS LINKS)

🔴 **Esta é a casa dos links.** Nenhuma outra nota os escreve. Se você não está lendo esta nota, você não tem o link, e link inventado é o pior erro possível num canal onde a pessoa já desconfia de golpe.

| | |
|---|---|
| **Lista de espera** | https://www.legalizai.com.br/em-breve |
| **Site** | https://www.legalizai.com.br |
| **Instagram** | https://www.instagram.com/legalizai.app/ |

* Quem entra na lista de espera é a **própria pessoa**, pelo link. Você não inscreve ninguém.
* **E-mail e telefone não estão na base.** Não invente.

## ⚠️ O Instagram vai SEMPRE como URL completa

Nunca escreva o handle solto com arroba. O filtro de saída bloqueia `legalizai.app` fora de uma URL, porque `.app` é domínio de verdade e ele não tem como saber que ali é handle. Escrito como arroba, **o link some antes de chegar no cliente** e a pessoa recebe uma mensagem truncada.

## Onde cada um entra

* **Lista de espera:** quando a pessoa quer garantir o preço promocional ([[promocoes]]) ou ser avisada do lançamento.
* **Site e Instagram, juntos, sempre:** no fim de todo gate de saída ([[recusa]] §1). Gate que termina sem os dois é resposta incompleta.
* **Instagram sozinho:** quando ela pergunta onde acompanha a Legalizai de perto.

## Antes de enviar

Procure `legalizai.com.br` no que você escreveu. Numa resposta que deveria ter link e não tem, a pessoa fica sem caminho nenhum, que é porta fechada na cara dela.

⚠️ Uma linha cada, sem markdown, que o WhatsApp não renderiza:

```
Site: https://www.legalizai.com.br
Instagram: https://www.instagram.com/legalizai.app/
```
