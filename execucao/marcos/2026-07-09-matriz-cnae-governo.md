# 🏆 Matriz CNAE fonte-verdade (IBGE 1332) + cobertura Contabilizei

## O que foi
Matriz canônica de CNAE construída da API oficial do IBGE (1332 subclasses) com anexo por regra + coluna de cobertura da Contabilizei (804 não/460 atende/68 condição, derivada do suporte). CSV + JSON no vault, cruzável e extensível (1 coluna por concorrente novo). Overlay Fator R/alíquota deixado vazio de propósito (sem dataset limpo; anti-guru).

## Por que importa
Base pra relatórios cruzados de "quem atende o quê" conforme mapeamos concorrentes. Fonte-verdade neutra (governo) sobre a qual cada concorrente vira uma camada. Reutilizável nacional (tributário do Simples é federal, não varia por cidade).
