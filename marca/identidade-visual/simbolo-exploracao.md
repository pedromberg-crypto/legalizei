# 🔣 Exploração de símbolo — Legalizei (rascunhos)

> Direção conceitual: **"Legalizei = consegui"** (1ª pessoa, passado = conquista). Rascunhos vetoriais (SVG mão-livre) pra provocar direção — **Pedro (designer) leva pro processo humano de criação de marca**. Retomar debate depois. Cor/arquétipo/tom já travados ([[decisoes-marca]], [[paleta-cores]], [[conceito-marca]]).

## Caminhos rascunhados
| Cód | Ideia | Leitura |
|---|---|---|
| ~~A~~ | L que vira check | ❌ **descartado** — execução virou "ponteiro de relógio" (dois traços saindo do mesmo ponto). Conceito ok, execução ruim. |
| B1 | pingo do "i" = check | Assina o "-i" que diferencia da matriz "Legalize". Ótimo como **logotipo**; fraco isolado. |
| B2 | pingo do "i" = brilho (sparkle) | "Conquista/celebração". Risco: sparkle virou clichê de IA. |
| B3 | ícone isolado: o "i" cujo pingo é check | Ownável, amarra no nome. Candidato a **ícone de app** do time B. |
| C1 | selo quadrado + check | Já tem forma de ícone de app. |
| C2 | carimbo redondo + check | O mais "burocracia carimbada/vencida". Lê bem pequeno. |
| C3 | badge/medalha + check | Vira **conquista/medalha** — casa com o arquétipo vitorioso. |

## Leitura de sistema (pra retomar)
- **Logotipo = B1** (check no pingo do "i", fixo) + **ícone de app = B3 ou C3.**
- B3 = sistema mais coeso (tudo sai do "i"). C3 = mais emoção (medalha/conquista).
- Pedro vai preferir refinar no processo humano — estes são só pontos de partida.
