# Diário da Imersão

1 nota por dia dentro da Legalize, nome `AAAA-MM-DD.md`, a partir de `_templates/diario-imersao.md`.

Regra: **fato primeiro, interpretação depois.** O que você VIU vai em "O que vi"; o que você ACHA vira `#insight` linkado. É daqui que a spec do produto nasce.

Começa em 2026-07-08 (dia 1).
